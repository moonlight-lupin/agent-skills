# Principles Index (one-principle skills — load on demand)

An index only. Each entry names one principle from Lauren Tan's pstack pack
(MIT, verified 2026-11-28); load the upstream principle skill when applying it.
Do not restate the principles here — this file routes, it does not teach.

| Principle | What it governs | Pull it when |
|---|---|---|
| `principle-laziness-protocol` | Solving problems once, at the right layer | You are about to fix a symptom that will recur |
| `principle-attack-the-premise` | Testing shared assumptions before repeat attempts | Two fixes failed on the same premise (see also the `debug` stop rule) |
| `principle-build-the-lever` | Building the reusable force multiplier first | Manual effort is about to repeat across tasks |
| `principle-explain-the-number` | Quantifying claims before acting on them | A decision leans on an unverified magnitude |
| `principle-encode-lessons-in-structure` | Turning corrections into mechanisms | A correction would otherwise live only as prose (see also `review-lessons` rule-to-enforcer) |
| `principle-sequence-verifiable-units` | Splitting work into independently verifiable steps | A plan step cannot name its own verification |
